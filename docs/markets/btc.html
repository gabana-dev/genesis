What happens if a cluster is reached? Less than you would think, and we can now say why. Forced flow at 15 minutes returned +40.07 bps — and a random minute in the same hour returned 44.52 bps. The mechanism is below: a cluster is small against the book it would have to move, so it arrives on the move rather than causing it. The full test →

How big is any of this, really?

Every liquidation map scales its clusters against each other, so the biggest one always looks like a wall. Against the liquidity actually standing in front of it, it usually is not.

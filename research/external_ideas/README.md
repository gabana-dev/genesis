# External ideas

Imported ideas — from reading, from other people, from AI suggestions — held here,
**clearly marked as unadopted**, until the researchers decide what to do with them.

This folder is a holding area, not the canon. An idea living here has *not* been accepted
into Genesis. It is a candidate. This is where an AI-originated or outside suggestion goes
so it can be considered without contaminating the foundations — nothing here shapes the
project until a researcher deliberately graduates it.

## Format

One file per idea: `short-slug.md`.

```
# <Idea>

**Source:** <where it came from — a book, a person, a model, a conversation.>
**Status:** unadopted

## The idea
<a faithful summary.>

## Why it might matter to Genesis
<the relevance, stated honestly — including reasons it might not fit.>

## Disposition
<left open until the researchers decide: adopt (→ author into the canon with a decision
record), keep watching, or discard.>
```

## Notes

- Anyone — including AI — may file an idea here. Filing it is not adopting it.
- Adoption is a separate, deliberate act by the researchers, recorded as a
  [decision](../decisions/). Only then does it enter the canon.

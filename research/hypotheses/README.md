# Hypotheses

What we suspect but have not tested.

A hypothesis is not a decision, and the difference is the whole point of this folder:

- **Decision** — *we believe X.* A choice made, recorded in [`../decisions/`](../decisions/).
- **Hypothesis** — *we suspect X but haven't tested it.*

A hypothesis is held openly, at stated confidence, expecting to be tested and possibly
falsified. A hypothesis that turns out wrong is not a failure of the folder — it is the
folder working. Being able to look back later and see which suspicions survived is the
record of a research program actually doing science.

How a hypothesis becomes a decision, and a decision becomes canon, is defined in
[`../../canon/research-methodology.md`](../../canon/research-methodology.md) (authored by
the researchers).

## Format

One file per hypothesis: `NNNN-short-slug.md`. Each contains:

```
# NNNN · <Title>

**Status:** open | supported | weakening | rejected (→ link)
**Current confidence:** <how strongly held, on whatever scale you adopt>
**Last reviewed:** YYYY-MM-DD

## Question
<the question the hypothesis answers.>

## Hypothesis
<what we suspect — stated plainly.>

## Why we think so
<the reasoning behind the suspicion.>

## Supporting evidence
<what points toward it so far.>

## Counterarguments
<what points against it, and what would falsify it.>

## Experiments
<what would test it. Link entries in ../experiments/.>
```

## Notes

- Hypotheses are **authored by the researchers**. Claude maintains form only (structure,
  formatting, links) per the
  [Governing Principle](../../ai/collaboration.md#governing-principle).
- Confidence and *Last reviewed* are meant to change. Revisit them; let the record show
  the movement.

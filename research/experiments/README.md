# Experiments

Things tried, and what they showed. The place where claims meet reality.

Per the project's discipline, everything is a hypothesis until it survives a test. An
experiment states what it expected to find *before* running, so the result can't be
quietly reinterpreted to fit. Negative results are kept — they are often the most
informative entries here.

## Format

One file per experiment: `YYYY-MM-DD-short-slug.md`.

```
# <Experiment title>

**Date:** YYYY-MM-DD
**Status:** planned | running | done

## Hypothesis
<what we expected, and why — stated before running.>

## Setup
<what was done, precisely enough to repeat.>

## Result
<what actually happened.>

## What it changes
<what we now believe differently. Link any decision it triggers.>
```

## Notes

- Authored by the researchers. AI may format, and may help build tooling for an experiment
  once `src/` opens — but does not decide what an experiment means.

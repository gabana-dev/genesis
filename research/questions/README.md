# Questions

Open problems. The frontier of what Genesis does not yet know.

A research program that is working produces a narrowing, deepening set of questions — not
a widening pile of vague ones. This folder is where the honest state of our ignorance is
kept in view. "I don't know yet" is a complete and respectable entry.

## Format

One file per question, or a grouped file for a cluster: `short-slug.md`.

```
# <The question>

**Status:** open | narrowing | answered (→ link) | dissolved
**Weight:** how much rests on it — does the project's direction depend on the answer?

## Why it matters
<what turns on this question.>

## What we know so far
<the current state of thinking. Link relevant journal entries.>

## What would move it
<what evidence, argument, or experiment would sharpen or resolve it.>
```

## Notes

- Authored by the researchers. AI may surface *that* a question seems unresolved or
  contradicted elsewhere — it does not answer foundational questions on the project's
  behalf.
- A question that gets answered is marked and linked to where the answer lives, not
  deleted. A question that turns out to be malformed is marked *dissolved*, with why.

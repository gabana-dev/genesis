# Journal

Chronological thinking. Where research happens on the page before it is anything else.

The journal is not a summary of work done elsewhere — per the project's discipline,
thinking that isn't written didn't fully happen. Entries are dated, kept in order, and not
rewritten to hide the path taken. A wrong turn recorded honestly is worth more than a
clean story invented later.

## Format

One file per entry: `YYYY-MM-DD-short-slug.md`. Multiple entries in a day are fine — add a
suffix (`-2`, or a time).

```
# YYYY-MM-DD — <title>

<the thinking>
```

## Notes

- Entries are authored by the researchers. AI may format, tighten for clarity, or fix
  links — never change what was thought or claimed.
- When journal thinking hardens into a choice, capture it as a
  [decision record](../decisions/) so the canon can trace back to it (provenance).

# ai/ — Working memory for AI collaborators

If you are an AI opening this repository cold, this folder is how you regain context. Read
it before doing anything else.

## Read in this order

1. **[`collaboration.md`](collaboration.md)** — the contract. What you may and may not do.
   Binding. Read it first, every time.
2. **[`project_state.md`](project_state.md)** — the current snapshot: what exists, what's
   in progress, what's blocked.
3. **[`current_focus.md`](current_focus.md)** — the single thing being worked on right now.
4. **[`terminology.md`](terminology.md)** — the shorthand used across the repo.

Then, for the substance of the project, go to the canon in [`../docs/`](../docs/).

## The purpose of this folder

The rest of the repository is the project. This folder is the *memory of working on it* —
the state that would otherwise be lost when a session ends and a new one (possibly a
different model) begins. It is the difference between resuming and restarting.

## How to keep it current

- Update `current_focus.md` when the focus changes.
- Update `project_state.md` when something meaningful is completed, started, or blocked.
- Keep these short. This folder is a dashboard, not an archive — the archive is
  [`../research/`](../research/).
- These files describe *state and activity*, never project substance. Substance lives in
  the canon and is authored by the researchers.
